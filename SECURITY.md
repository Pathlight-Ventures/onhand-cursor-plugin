# Security policy

## Reporting a vulnerability

Email **help@askonhand.com**. This is the only published security contact, as listed in Onhand's
[security.txt](https://askonhand.com/.well-known/security.txt) (also served at
https://mcp.askonhand.com/.well-known/security.txt).

Please include what you found, the URL or tool involved, and steps to reproduce. Do not include
other people's personal information in your report.

## Scope

- The hosted MCP endpoint: `https://mcp.askonhand.com/mcp/cursor`
- The files in this repository

## Not security reports

- Privacy requests (access, correction, deletion): privacy@askonhand.com
- General support: help@askonhand.com

This policy does not promise a response time, a bounty, or an encrypted channel. None is published.
